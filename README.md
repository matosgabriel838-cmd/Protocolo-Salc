de# SisGEC - Management System for Commitments and Credits

This project is a Next.js application built within Firebase Studio.

## About

SisGEC is a system designed to manage military financial commitments and credits. It provides functionalities for tracking protocols, credit notes, and generating compliance reports.

## Getting Started

This is a starter project. To begin development, explore the `src/app` directory, starting with `src/app/page.tsx`.
